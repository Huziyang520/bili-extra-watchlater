# B站额外稍后再看

一个本地收藏的 Chrome / Edge 扩展（Manifest V3），在 B 站视频卡片上叠加「稍后」按钮，把视频加入自建的稍后再看列表。与原版「稍后再看」相互独立，不读取、不修改 B 站账号数据。

## 功能

- 首页推荐、搜索结果、分区列表、播放页推荐等处的视频卡片右上角会出现「+ 稍后」按钮，点击即加入当前列表，按钮变为「✓ 已加入」。
- 右下角悬浮胶囊可切换目标列表、查看当前列表占用（如 `128/1000`）、打开管理页；胶囊可拖动，位置保存在本机。
- 支持多个列表，列表名可自定义，每个列表容量默认 1000 条（可在 10–5000 之间调整）。达到上限时点击会明确提示，不会静默丢弃。
- 管理页：查看与删除条目、按标题 / BV 号搜索（可切换只在当前列表或全部列表内搜索）、新建 / 重命名 / 删除列表、调整容量、导出 JSON、合并导入备份。
- 数据只写入 `chrome.storage.local`，扩展不发起任何网络请求。
- 界面跟随系统深色 / 浅色；页面上的按钮与胶囊都挂在 Shadow DOM 内，不受站点样式影响。

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」。
2. 点「加载解压缩的扩展」，选择本目录（含 `manifest.json` 的那一层）。
3. 打开任意 B 站页面，卡片右上角出现「稍后」按钮即生效。

## 使用

- 点卡片上的「稍后」：加入胶囊里当前选中的列表。
- 点胶囊里的下拉框：切换目标列表（选择会记住）。
- 点胶囊「管理」或工具栏图标：打开管理页。
- 管理页「导出 JSON」：备份全部列表与条目；「导入备份」按 BV 号合并，同名列表不会重复添加。

## 数据位置

- 数据存放在扩展的 `chrome.storage.local`，磁盘位置为：
  - Chrome：`%LOCALAPPDATA%\Google\Chrome\User Data\<配置文件>\Local Extension Settings\<扩展ID>`
  - Edge：`%LOCALAPPDATA%\Microsoft\Edge\User Data\<配置文件>\Local Extension Settings\<扩展ID>`
  - `<配置文件>` 对应 `chrome://version` 中「个人资料路径」的最后一段（通常是 Default）。
- 扩展 ID 与管理页上显示的数据目录可在管理页顶部「数据保存在本机」一栏直接复制。
- 导出的 JSON 保存到浏览器默认下载目录，可在 `chrome://settings/downloads` 查看或修改。
- 卸载扩展、移动插件文件夹或换用另一个浏览器配置后，扩展 ID 会变化，旧数据仍在磁盘上但新扩展读不到；需要迁移时先导出 JSON，装好后导入。

## 权限

- `storage`：保存列表与条目。
- 内容脚本运行在 `https://*.bilibili.com/*`，用于识别视频卡片并注入按钮，不申请 `tabs`、`cookies`、`webRequest` 等权限。
